# Furry Friends — website preview

Pet grooming in Jumeirah Village Circle, Dubai. One page (`index.html`), English and Arabic, every "Book" button opens WhatsApp with the message ready.

- Edit `src.html`, then `python3 build.py 9715XXXXXXXX` (the shop's WhatsApp number) to make `index.html`.
- Photos: `photos/*.webp` (Unsplash, free to use) — swap in the shop's own photos when we have them.
- `?wa=9715XXXXXXXX` tries another WhatsApp number without rebuilding; `?lang=ar` opens in Arabic.
- Remove the `noindex` line in `src.html` when this becomes the shop's real site.
